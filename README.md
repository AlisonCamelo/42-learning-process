# 🧪 42 Learning Process & Project Laboratory

Welcome to my personal 42 School development journal! 🚀

This repository serves as a **behind-the-scenes engineering log**. Instead of just storing final, polished code, this space captures the raw learning curve: initial experiments, mental models, memory leaks, edge-case breakdowns, and visual schematics.

> *"First make it work, then make it right, then make it fast. But above all, understand why it works."*

---

## 🧠 Philosophy & Methodology

Every project folder in this repository contains:
* 📝 **Concept Trials:** Small, isolated C exercises built to master specific concepts before tackling the main project.
* 🎨 **Visual Architecture:** Diagrams and memory flowcharts drawn in **Excalidraw** to visualize pointers, stack vs. heap memory, and data structures.
* 🐛 **Bloopers & Edge Cases:** Documented segmentation faults, leaks, and logic bugs encountered during development.
* 📄 **Deep-Dive READMEs:** Dedicated documentation explaining the inner workings of each project module.

---

## 🛠️ Visual Diagrams (Excalidraw)

All visual schematics embedded in the project subdirectories are created using **Excalidraw**. 
* High-resolution screenshots (`.png`) are embedded directly in each folder's `README.md`.
* Raw `.excalidraw` source files are stored in `assets/` subfolders for easy editing.
